Organised outputs

Bad-channel outputs are organised by session and shank, under the output folder you choose.

  • CSV files contain channel IDs and labels for each recording.
  • Session unions include the contributing session names and generation date in YAML.

Use preloaded SpikeInterface recordings

Load recordings with SpikeInterface, then pass them into the Python API. Use a single recording, named sessions, or recordings already split by shank.

This example runs bad-channel detection using your own YAML configuration.

import spikeinterface as si
from spikesorted.pipeline.pipeline import Pipeline

recording = si.load("/data/saved_recording")

Pipeline(
    recordings=recording,
    config_path="my_pipeline.yaml",
    output_path="/results/subject_01",
    stop_after_step="bad_channel_detection",
).run()
Minimal my_pipeline.yaml
bad_channel_detection:
  method: coherence+psd
